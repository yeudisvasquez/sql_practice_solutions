## 📚 What I Learned

Completing the challenges reinforced an important lesson: **SQL is not only about knowing commands—it is about thinking logically about data.**

For each problem, I practiced breaking the requirement down into smaller questions:

1. What information am I being asked to retrieve?
2. Which table or tables contain that information?
3. Do I need to filter the data?
4. Do I need to aggregate results?
5. Do I need to join multiple tables?
6. Do I need a subquery or conditional logic?
7. Can the query be written more clearly or efficiently?

This process helped me become more comfortable translating a business or analytical question into a SQL query.
